I found this guide to Japanese traffic laws using Three.js and thought it was kind of silly because of how niche this is to generate code for. I think this is a great example of accessibility and a good use of educational tools. Something cute and fun like this could be a good way to ease someone into a practice and to remember rules/regulations. This could be applied to so many different things in communities outside Japanese drivers too.
